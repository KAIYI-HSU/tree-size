# Disk Usage Analyzer (Filelight clone)

這是一個基於 Python Streamlit 的網頁應用程式，類似於 Filelight。它可以分析 Linux 系統中指定路徑的資料夾容量，並以旭日圖（Sunburst Chart）呈現，協助用戶管理磁碟空間。

## 功能

1.  **容量分析**：輸入路徑，掃描並計算該路徑下的所有檔案與資料夾大小。
2.  **視覺化呈現**：使用互動式旭日圖顯示空間佔用情況。
3.  **檔案管理**：
    *   列出當前路徑下的項目。
    *   提供刪除功能。
    *   **雙重確認機制**：刪除前會顯示即將執行的 Linux 指令（如 `rm -rf ...`），確保用戶知情。

## 安裝與執行

### 前置需求

*   Python 3.8 或以上
*   建議在 Linux 環境下執行（刪除指令顯示為 Linux 格式）

### 安裝依賴

```bash
pip install -r requirements.txt
```

### 啟動應用程式

```bash
streamlit run app.py
```

## 使用說明

1.  啟動後，在網頁介面的輸入框中輸入想要分析的**絕對路徑**（例如 `/home/user/Downloads`）。
2.  點擊 **Analyze** 按鈕開始掃描。
3.  掃描完成後，查看圓餅圖分析結果。
4.  若需釋放空間，在下方選擇要刪除的檔案或資料夾。
5.  點擊刪除按鈕，系統會跳出警告並顯示 `rm` 指令。
6.  再次確認後，檔案將被永久刪除。
